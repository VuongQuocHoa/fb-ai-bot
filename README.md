# 💬 Facebook Fanpage AI Customer Assistant (Google Gemini 1.5 Flash)

> **Trợ lý bán hàng thông minh tự động hóa chăm sóc khách hàng và thu thập khách tiềm năng (Lead) 24/7**

Hệ thống bot AI tích hợp Facebook Messenger qua Graph API Webhooks, sử dụng mô hình ngôn ngữ lớn **Google Gemini 1.5 Flash** để tư vấn sản phẩm, thấu hiểu ngữ cảnh khách hàng và tự động thu thập tên, số điện thoại đặt hàng 24/7.

---

## 🌟 Tính Năng Nổi Bật

- **Phản hồi siêu tốc:** Tận dụng Google Gemini 1.5 Flash với thời gian phản hồi < 1.5 giây.
- **Phễu bán hàng tự động:** Tự động dẫn dắt cuộc hội thoại và thu thập thông tin khách hàng tiềm năng.
- **Live Transaction Logging:** Bảng điều khiển theo dõi lịch sử tin nhắn và trạng thái giao dịch thời gian thực.
- **Quản trị phiên trò chuyện:** Bộ nhớ đệm In-memory lưu trữ ngữ cảnh hội thoại của từng người dùng.

---

## 🚀 Hướng Dẫn Vận Hành

```powershell
npm install
node server.js
```
Mở giao diện cấu hình và giám sát: **http://localhost:3000**
